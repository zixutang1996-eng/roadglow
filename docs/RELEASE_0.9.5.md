## RoadGlow 0.9.5

**从 0.9.4 升级：** 菜单 → 检查更新 → 下载并安装。签名和以前一样，直接覆盖安装，数据都会保留。

### 新皮肤（每套都有浅色和深色）
- **深空**：极简星图风，用细线和等宽字体，少量彩色条纹做点缀。定位点外面有一圈轨道环，深色版带星空背景，菜单底部是轨道徽记。
- **北境**：雾灰色羊皮纸地图配烟熏色面板。标题和分隔线两端有卷轴结饰，关闭按钮是菱形。导航时顶部会出现罗盘条。
- **战术**：建筑是实心色块，导航时变成实心 3D 楼块，网格也会隐藏。定位点是投弹准星，分隔线用声波加心跳线。菜单底部是老兵剪影。
- 在“地图风格”里选。地图上的中文地名都能正常显示。

### 荒野墨图改版
- 搜索栏、所有菜单、窗口、按钮、标签和关闭按钮都加了一圈手工皮具缝线（蜡线加压纹槽）。地图上没有缝线。
- 浅色地图的底色稍微暖黄了一些。

### 皮肤与语音包（新）
- 菜单 → 皮肤与语音包：可以在线安装、更新、切换和移除。切换后马上生效，不用重启。
- 以后出新的皮肤包或语音包，不需要更新 App。
- 也能从本地文件安装：在 App 里选文件，或者用 RoadGlow 打开、分享 .rgpack 文件。
- 安装前会校验 SHA-256。
- 附带两个示例包：“蓝图”皮肤和“平静播报”语音。

### 修复和体验
- 搜索栏下面的快捷按钮，每个都有自己独立的阴影，不再连成一整条。
- 每套皮肤的字体和素材只在选中时才加载。
- 所有动画只用位移和透明度。

### 说明
- 只在电脑上模拟手机屏幕测试过，没有在真机上测试。
